02 / 07
Introduction

Problem & Solution

⚠️

The Problem

Small businesses (bakeries, clinics, salons) lack the technical skills and budget to build a professional online store or booking system from scratch.

✅

Our Solution

BizWiz lets any business owner create a fully customizable e-commerce store, booking portal, or landing page in minutes — zero coding required.

Key Features

Google OAuth Login 3 Template Types Real-time Booking Slots AI Content Generation Coupon System Order Management Analytics Dashboard Dynamic Theming
03 / 07
Technology Stack

Development Tools

Front-end

  • React.js v19 — Component-based UI
  • Vite — Fast dev server & build tool
  • Tailwind CSS — Utility-first styling
  • React Router v7 — Client-side routing
  • Axios — HTTP client for API calls
  • Google OAuth — Secure authentication

Back-end

  • Node.js + Express.js — REST API server
  • MongoDB Atlas + Mongoose — Cloud NoSQL DB
  • JWT — Token-based session management
  • Google Auth Library — Token verification
  • Gemini AI SDK — Content generation
  • CORS + dotenv — Security & config

Architecture

System Architecture

Frontend — React.js + Vite + Tailwind

LandingPage  |  LoginPage  |  OnboardingWizard  |  AdminDashboard  |  SiteRenderer

Templates:  E-commerce Booking Landing

▼   Axios (HTTP / REST API calls)   ▼

Backend — Node.js + Express.js

Middleware: CORS, JSON Parser, JWT Auth

Routes:   /api/auth  |  /api/tenant  |  /api/ai

▼   Mongoose ODM   ▼

Database — MongoDB Atlas (Cloud)

Collections:   Users   |   Tenants (+ embedded Items, Orders, Coupons)
